# Atribuciones de terceros

## Modelo y tokenizador

DistilBERT base uncased, de la comunidad DistilBERT / Hugging Face:
https://huggingface.co/distilbert/distilbert-base-uncased

La ficha del modelo identifica la licencia Apache-2.0. Se incluye una copia en
`licencias/Apache-2.0.txt`. La revisión de base y las modificaciones de fine-tuning
están registradas en `modelo_final/metadata.json` y `NOTICE.txt`.

Sanh, V., Debut, L., Chaumond, J., y Wolf, T. (2019). DistilBERT, a distilled
version of BERT: Smaller, faster, cheaper and lighter. https://arxiv.org/abs/1910.01108

## Datos

Fuente: Rohit Sahoo, Superstore Sales Dataset, Kaggle:
https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting

La documentación del proyecto original registra GPL 2 para este conjunto de datos.
Se conserva esa atribución y una copia de GPL-2 en `licencias/GPL-2.txt`.
La base SQLite de este despliegue es un derivado académico reducido a atributos
de productos. No se redistribuye aquí el CSV original con datos de clientes.

## Identidad institucional y código

El logotipo de CUN se conserva como identificación académica; no implica patrocinio
ni cesión de derechos de marca. No se ha asignado una licencia nueva al código
original de los integrantes. Las licencias indicadas corresponden a sus respectivos
componentes de terceros.
